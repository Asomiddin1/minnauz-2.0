# MinnaUz 2.0 — Plans & Feature Tiers

This document details the feature tiers, usage allowances, and access controls for MinnaUz users.

---

## 1. Plan Overview

MinnaUz provides structured access tiers to balance accessibility for beginner learners with premium AI capabilities and advanced JLPT preparation.

| Feature / Capability | Free (Boshlangʻich) | Premium Pro (Pro Obuna) |
|---|---|---|
| **Hiragana & Katakana Basics** | Full Access | Full Access |
| **JLPT N5 Course (Introductory)** | First 5 Lessons Free | Complete Access (All 25 Lessons) |
| **JLPT N4, N3, N2, N1 Courses** | Locked (Preview only) | Full Access |
| **Interactive Vocabulary (Kotoba)** | Basic audio & translations | Audio, furigana & sample sentences |
| **Grammar Explanations (Bunpou)** | Standard text | In-depth rules, examples & audio |
| **Kanji & Stroke Order Visuals** | Standard | Full stroke animations & radicals |
| **Practice Quizzes (Renshuu)** | Limited drills | Unlimited tests & explanations |
| **AI Speaking (Kaiwa Practice)** | 3 AI dialogues / week | Unlimited AI conversational practice |
| **Multi-device Sync** | Up to 3 devices | Up to 3 devices |
| **Offline / PDF Materials** | Not available | Downloadable JLPT guides |
| **Teacher Group Support** | Yes | Yes |

---

## 2. Usage Quotas & Limits

### 2.1 AI Speaking Daily Quota
- **Free Tier**: Capped at 3 speaking roleplay exchanges per week to introduce users to conversational AI.
- **Premium Tier**: Unmetered daily access subject to fair usage policies (e.g. 50 interactive dialogues / day).

### 2.2 Reaching a Limit
When a student reaches a plan limit:
1. The UI displays an upgrade CTA modal (`PlanModal`).
2. The user is redirected to the `/dashboard/premium` checkout page.
3. No data is lost; progress on unlocked content remains permanently saved.
