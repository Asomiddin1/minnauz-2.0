# MinnaUz 2.0 — Database Design & Schema

This document details the complete PostgreSQL database schema managed via **Prisma ORM** (`api/prisma/schema.prisma`).

---

## 1. Enums

| Enum | Values | Description |
|---|---|---|
| `Role` | `USER`, `TEACHER`, `ADMIN`, `SUPER_ADMIN` | User access privileges |
| `CourseLevel` | `N5`, `N4`, `N3`, `N2`, `N1`, `OTHER` | Japanese proficiency levels according to JLPT |
| `ExerciseType` | `QUIZ`, `AUDIO_LISTENING`, `FILL_BLANK`, `MATCHING` | Types of practice exercises in Renshuu |
| `BannerAudience` | `ALL`, `USER`, `TEACHER` | Target audience filter for dashboard banners |
| `BannerActionType`| `LINK`, `PLAN_MODAL`, `NOTIFICATION_DETAIL` | Behavior triggered when clicking banner CTA |
| `NotificationAudience` | `ALL`, `USER`, `TEACHER`, `INDIVIDUAL` | Target group for notifications |
| `NotificationType` | `INFO`, `ANNOUNCEMENT`, `SYSTEM`, `UPDATE`, `PROMO` | Category badge for notification cards |

---

## 2. Models & Tables Breakdown

### 2.1 `User` (`users`)
Stores primary user accounts and credentials.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Unique User UUID |
| `email` | String | `@unique` | Email address used for authentication |
| `fullName` | String? | Optional | Full display name |
| `avatarUrl` | String? | Optional | Profile avatar image URL |
| `role` | Role | `@default(USER)` | Current permission role |
| `isVerified` | Boolean | `@default(false)` | Email verification flag |
| `createdAt` | DateTime | `@default(now())` | Account registration timestamp |
| `updatedAt` | DateTime | `@updatedAt` | Last modification timestamp |

**Relations:**
- `sessions`: 1-to-many with `DeviceSession` (Cascade delete).
- `otpCodes`: 1-to-many with `OtpCode` (Cascade delete).
- `authoredCourses`: 1-to-many with `Course` (SetNull on delete).
- `lessonProgress`: 1-to-many with `UserLessonProgress` (Cascade delete).
- `teachingGroups`: 1-to-many with `Group` as teacher (Cascade delete).
- `groupMemberships`: 1-to-many with `GroupMember` (Cascade delete).
- `studyActivities`: 1-to-many with `UserStudyActivity` (Cascade delete).
- `studyPlan`: 1-to-1 with `UserStudyPlan` (Cascade delete).
- `notifications`: 1-to-many with `UserNotification` (Cascade delete).

---

### 2.2 `DeviceSession` (`device_sessions`)
Enforces maximum 3 simultaneous devices per account with hashed refresh tokens.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Session UUID |
| `userId` | String | Foreign Key | References `User.id` |
| `deviceId` | String | `@unique` | Unique client device UUID generated by frontend |
| `deviceName` | String?| Optional | Client device signature (e.g. "Chrome on Windows") |
| `os` | String?| Optional | Operating system name |
| `browser` | String?| Optional | Web browser name |
| `ipAddress` | String?| Optional | Client IP address at last login |
| `refreshToken`| String | Required | Securely hashed refresh token |
| `lastActiveAt`| DateTime| `@default(now())` | Timestamp of last API interaction |
| `createdAt` | DateTime| `@default(now())` | Session creation timestamp |

---

### 2.3 `OtpCode` (`otp_codes`)
Manages transient 6-digit one-time passcodes for passwordless login.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Passcode UUID |
| `email` | String | Required | Target email address |
| `code` | String | Required | 6-digit numeric verification code |
| `expiresAt` | DateTime | Required | Expiration timestamp (typically 5 minutes from issue) |
| `used` | Boolean | `@default(false)` | Flag set to true upon successful consumption |
| `createdAt` | DateTime | `@default(now())` | Generation timestamp |
| `userId` | String? | Foreign Key | Optional reference to existing `User.id` |

---

### 2.4 `Course` (`courses`)
Top-level Japanese curriculum course container.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Course UUID |
| `title` | String | Required | Course name (e.g. "Minna no Nihongo I (N5)") |
| `slug` | String | `@unique` | URL slug (e.g. "n5-minna-no-nihongo-1") |
| `description` | String?| Optional | Course overview & syllabus |
| `level` | CourseLevel| `@default(N5)` | JLPT level |
| `coverImage`| String?| Optional | Thumbnail banner image URL |
| `authorId` | String?| Foreign Key | References `User.id` (Teacher/Admin) |
| `isPublished`| Boolean| `@default(true)` | Visibility toggle |
| `order` | Int | `@default(1)` | Sort order |

**Relations:**
- `modules`: 1-to-many with `CourseModule` (Cascade delete).
- `groups`: 1-to-many with `Group` (SetNull on delete).

---

### 2.5 `CourseModule` (`course_modules`)
Chapters or modular groupings inside a course.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Module UUID |
| `courseId` | String | Foreign Key | References `Course.id` |
| `title` | String | Required | Module title (e.g. "1-10 darslar: Asosiy grammatika") |
| `description`| String? | Optional | Module summary |
| `order` | Int | `@default(1)` | Display order inside course |

**Relations:**
- `lessons`: 1-to-many with `Lesson` (Cascade delete).

---

### 2.6 `Lesson` (`lessons`)
Individual lesson containing Japanese learning sections and practice drills.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Lesson UUID |
| `moduleId` | String | Foreign Key | References `CourseModule.id` |
| `title` | String | Required | Lesson title (e.g. "1-Dars: Tanishuv va shaxsiy olmoshlar") |
| `japaneseTitle` | String? | Optional | Japanese label (e.g. "第1課") |
| `slug` | String? | Optional | URL identifier |
| `order` | Int | `@default(1)` | Lesson sequence number |
| `videoUrl` | String? | Optional | Video lecture (Local upload path or YouTube URL) |
| `summary` | String? | Optional | Quick lesson overview markdown |
| `kaiwaScenario` | Json? | Optional | AI roleplay context, character, goal, vocabulary prompts |
| `isPublished` | Boolean | `@default(true)` | Publication toggle |

**Relations:**
- `kotobaItems`: 1-to-many with `KotobaItem` (Cascade delete).
- `bunpouItems`: 1-to-many with `BunpouItem` (Cascade delete).
- `kanjiItems`: 1-to-many with `KanjiItem` (Cascade delete).
- `renshuuItems`: 1-to-many with `RenshuuItem` (Cascade delete).
- `userProgress`: 1-to-many with `UserLessonProgress` (Cascade delete).

---

### 2.7 `KotobaItem` (`kotoba_items`)
Vocabulary entries with multilingual translations and pronunciation audio.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Word UUID |
| `lessonId` | String | Foreign Key | References `Lesson.id` |
| `word` | String | Required | Word in Kanji/Kana (e.g. "わたし" or "私") |
| `furigana` | String? | Optional | Furigana reading (e.g. "わたし") |
| `romaji` | String? | Optional | Latin transliteration (e.g. "watashi") |
| `meaningUz` | String | Required | Uzbek translation (e.g. "men") |
| `meaningRu` | String? | Optional | Russian translation (e.g. "я") |
| `meaningEn` | String? | Optional | English translation (e.g. "I, me") |
| `partOfSpeech`| String?| Optional | Grammatical category (e.g. "Ot", "Fe'l", "Sifat") |
| `audioUrl` | String? | Optional | Pronunciation audio file URL |
| `sampleSentence` | String? | Optional | Example sentence in Japanese |
| `sampleSentenceUz` | String? | Optional | Example sentence translation in Uzbek |
| `order` | Int | `@default(1)` | Display order |

---

### 2.8 `BunpouItem` (`bunpou_items`)
Grammar rules and sentence pattern structures.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Grammar UUID |
| `lessonId` | String | Foreign Key | References `Lesson.id` |
| `title` | String | Required | Rule title (e.g. "~ は ~ です") |
| `structure` | String? | Optional | Formula (e.g. "N1 は N2 です") |
| `explanationUz`| String | Required | Detailed explanation in Uzbek |
| `explanationRu`| String? | Optional | Explanation in Russian |
| `examples` | Json? | Optional | Array of `{ japanese, romaji, uzbek }` objects |
| `order` | Int | `@default(1)` | Display order |

---

### 2.9 `KanjiItem` (`kanji_items`)
Kanji characters, stroke orders, readings, and example compounds.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Kanji UUID |
| `lessonId` | String | Foreign Key | References `Lesson.id` |
| `character` | String | Required | Single Kanji character (e.g. "日") |
| `onyomi` | String? | Optional | Chinese readings (e.g. "ニチ, ジツ") |
| `kunyomi` | String? | Optional | Japanese readings (e.g. "ひ, -び, -か") |
| `meaningUz` | String | Required | Uzbek definition (e.g. "Quyosh, kun") |
| `meaningRu` | String? | Optional | Russian definition (e.g. "Солнце, день") |
| `strokeCount` | Int? | Optional | Total brush strokes (e.g. 4) |
| `strokeOrderData` | String? | Optional | Stroke diagram SVG or animation link |
| `radical` | String? | Optional | Root radical (e.g. "日") |
| `examples` | Json? | Optional | Array of `{ word, reading, meaning }` |
| `order` | Int | `@default(1)` | Display order |

---

### 2.10 `RenshuuItem` (`renshuu_items`)
Interactive exercises for testing knowledge.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Exercise UUID |
| `lessonId` | String | Foreign Key | References `Lesson.id` |
| `type` | ExerciseType | `@default(QUIZ)` | Exercise format |
| `question` | String | Required | Prompt question text |
| `audioUrl` | String? | Optional | Listening drill audio track URL |
| `options` | Json? | Optional | Array of choice strings: `string[]` |
| `correctAnswer`| String | Required | Exact match answer string |
| `explanation` | String? | Optional | Post-submission explanation |
| `order` | Int | `@default(1)` | Exercise sequence number |

---

### 2.11 `UserLessonProgress` (`user_lesson_progress`)
User completion tracking per lesson.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Progress UUID |
| `userId` | String | Foreign Key | References `User.id` |
| `lessonId` | String | Foreign Key | References `Lesson.id` |
| `completedSections` | Json? | Optional | Array of finished tabs e.g. `["kotoba", "bunpou", "kanji", "renshuu"]` |
| `quizScore` | Int? | Optional | Percentage score achieved (0-100) |
| `isCompleted` | Boolean | `@default(false)` | Flag indicating overall lesson completion |
| `lastStudiedAt` | DateTime | `@default(now())` | Timestamp of latest activity |

**Constraints:** `@@unique([userId, lessonId])`

---

### 2.12 `UserStudyPlan` (`user_study_plans`)
Personalized learning target settings.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Plan UUID |
| `userId` | String | `@unique` Foreign Key | References `User.id` |
| `targetLevel` | CourseLevel | `@default(N5)` | Goal JLPT level |
| `weeklyGoalHours` | Int | `@default(4)` | Target hours per week |
| `dailyMinutes` | Int | `@default(35)` | Target study minutes per day |
| `targetMonths` | Int | `@default(6)` | Timeline horizon in months |
| `isConfigured` | Boolean | `@default(true)` | Configuration flag |

---

### 2.13 `UserStudyActivity` (`user_study_activities`)
Daily study time logging for streak and heatmap calculations.

| Field | Type | Attributes | Description |
|---|---|---|---|
| `id` | String | `@id @default(uuid())` | Record UUID |
| `userId` | String | Foreign Key | References `User.id` |
| `date` | String | Required | Date string in ISO format (`YYYY-MM-DD`) |
| `minutesSpent` | Int | `@default(0)` | Total minutes logged on date |

**Constraints:** `@@unique([userId, date])`

---

### 2.14 `Banner` (`banners`) & `Notification` (`notifications`)
Promotional cards and system broadcasts.

**Banner Fields:**
- `id`, `title`, `desc`, `tag`, `tagIcon`, `image`, `btnText`, `btnUrl`, `btnIcon`, `actionType` (`LINK`, `PLAN_MODAL`, `NOTIFICATION_DETAIL`), `notificationId`, `order`, `isActive`, `isDismissible`, `targetAudience` (`ALL`, `USER`, `TEACHER`), `isDefault`.

**Notification Fields:**
- `id`, `title`, `message`, `content`, `imageUrl`, `videoUrl`, `actionUrl`, `actionText`, `audience` (`ALL`, `USER`, `TEACHER`, `INDIVIDUAL`), `targetUserId`, `type` (`INFO`, `ANNOUNCEMENT`, `SYSTEM`, `UPDATE`, `PROMO`), `isPublished`.

**UserNotification Fields:**
- `id`, `userId`, `notificationId`, `isRead`, `readAt`, `createdAt`.
- **Constraints:** `@@unique([userId, notificationId])`
